# REJECTED SOLUTIONS

Purpose: preserve durable engineering rationale for not using an existing solution.

No candidate is REJECTED yet.

## Required rejection record

```
ID:
NAME:
URL:
DATE:
PROBLEM:
VERSION/COMMIT:
TEST/INSPECTION:
EXPECTED_TO_REPLACE:
WHY_REJECTED:
EVIDENCE:
LIMITATIONS_OF_VERDICT:
REVISIT_CONDITION:
```

A solution is not rejected because it looks unfashionable, uses a different stack, or is larger than MP.
REJECT requires a material mismatch with MP requirements, evidence from inspection/test, or unacceptable integration/license/maintenance cost.

PARK is not REJECT.
