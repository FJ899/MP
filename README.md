# MP — Frankenstein Inspection Lab

Repozytorium robocze do audytu i integracji istniejących narzędzi analizy materiału z lotu inspekcyjnego.

Pierwszy cel nie jest produktem ani OMVS. Celem jest sprawdzenie, czy z około 30 minut filmu da się wyłonić ograniczoną listę sensownych miejsc do ponownego sprawdzenia przez operatora.
